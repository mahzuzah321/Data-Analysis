
# 📊 Sales Analysis Dashboard | Power BI

## 📌 Project Overview

The **Sales Analysis Dashboard** is an interactive Business Intelligence (BI) project developed using Microsoft Power BI to analyze sales performance, profitability, and business trends. It transforms sales data into meaningful visual insights, helping users monitor key performance indicators (KPIs), evaluate product performance, and explore geographic sales patterns.

The dashboard includes three report pages — **Summary, Analysis, and Details** — providing insights ranging from high-level performance monitoring to detailed data exploration.

## 🎯 Project Objectives

- **KPI Monitoring:** Track essential sales and profitability indicators.
- **Trend Analysis:** Understand changes in sales performance over time.
- **Product Performance:** Compare products and categories.
- **Geographic Analysis:** Explore regional sales distribution.
- **Interactive Exploration:** Investigate data through slicers, filters, and report navigation.
- **Data-Driven Decisions:** Present business information in an accessible format.
